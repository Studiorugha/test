# Studio Rugha
**Make Your Brand Roar.**

Praktische werkbasis voor een onafhankelijke brandingstudio: merkstrategie, visuele identiteit en merkcommunicatie voor startende en kleine ondernemers.

## Snel starten
1. Lees [de werkwijze](docs/werkwijze.md).
2. Kopieer [de projectbrief](templates/projectbrief.md) voor een nieuw project.
3. Gebruik [de opleverchecklist](templates/opleverchecklist.md) voor kwaliteitscontrole.
4. Houd taken bij via GitHub Issues; één taak per issue.

## Indeling
| Map | Inhoud |
| --- | --- |
| `docs/` | Studioprofiel en werkwijze |
| `templates/` | Herbruikbare briefing en opleverchecklist |
| `projects/` | Alleen openbare demo's en goedgekeurde cases |
| `assets/` | Goedgekeurde merkbestanden en gebruiksinstructies |
| `.github/` | Taaktemplate voor GitHub Issues |

## Afspraken
- Geef bestanden korte, duidelijke namen in `kebab-case`.
- Werk met kleine wijzigingen en beschrijvende commitberichten.
- Bewaar bronbestanden en grote exports in de eigen projectopslag; leg hier alleen geschikte bestanden of verwijzingen vast.
- Deze repository is **openbaar**. Plaats geen klantgegevens, contracten, wachtwoorden, vertrouwelijke strategie of ongepubliceerd werk. `.gitignore` is een hulpmiddel, geen beveiliging.
- Publiceer klantwerk alleen met toestemming en controleer de rechten op fonts, fotografie en andere assets.

## Techniek en uitbreiding
Dit is een documentatiebasis zonder app, dependencies of installatie.
Later kunnen een website, automatisering of extra templates worden toegevoegd zodra daar een concrete behoefte voor is.

## Rechten
Er is nog geen opensourcelicentie gekozen. Openbare toegang geeft niet automatisch toestemming om teksten, ontwerpen of merkbestanden te hergebruiken.
