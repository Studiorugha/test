# Openbare projecten

Maak per goedgekeurde case of fictief voorbeeld een map, bijvoorbeeld `demo-bakkerij/`.

Beschrijf daarin de vraag, strategische keuzes, het resultaat en de eigen rol. Voeg alleen bestanden toe waarvoor publicatierechten zijn gecontroleerd.

Bewaar klantbriefings, contracten en ongepubliceerd werk in een besloten omgeving.
