# Merkassets

Voeg hier later definitieve Studio Rugha-assets toe:
- `logos/`: goedgekeurde logo-exports.
- `brand/`: kleuren, typografie en gebruiksregels.
- `images/`: afbeeldingen met gecontroleerde publicatierechten.

Maak submappen pas wanneer er bestanden voor zijn. Voeg geen betaalde fontbestanden of ongecontroleerde stockbeelden toe. Beschrijf per extern asset de bron en gebruiksrechten.
